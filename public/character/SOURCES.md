# Character image sources

The 90 mini portraits are the original Eternal Return `CharCommunity_*_S000.png` assets, obtained from the public character page at https://dak.gg/er/characters/Jackie and its CDN:

`https://cdn.dak.gg/assets/er/game-assets/12.3.0/CharCommunity_{assetId}_S000.png`

Local filenames follow `characters.json` IDs. Asset-name aliases: Kiara → Chiara, Shou → Xiukai, Ian → Lyanh, Shurin → Xuelin, Justina → Justyna, Ishtvan → Istvan, NiaH → Niah, Yumin → YuMin.
