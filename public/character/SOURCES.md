# Character image sources

The 90 mini portraits are the original Eternal Return `CharCommunity_*_S000.png` assets, obtained from the public character page at https://dak.gg/er/characters/Jackie and its CDN:

`https://cdn.dak.gg/assets/er/game-assets/12.3.0/CharCommunity_{assetId}_S000.png`

Copyright belongs to Nimble Neuron. The files are included as character identifiers in this noncommercial fan game.

Local filenames follow `characters.json` IDs. Asset-name aliases: Kiara → Chiara, Shou → Xiukai, Ian → Lyanh, Shurin → Xuelin, Justina → Justyna, Ishtvan → Istvan, NiaH → Niah, Yumin → YuMin.

The full-body images under `full/` were supplied in `Downloads/characters/full`. `Default_Full.png` is Aiden and is stored locally as `Aiden.png`.

Celine, Felix, Alonso, and Henry were missing from the supplied folder. Their original full-body PNG files were obtained from the Eternal Return Wiki character artwork collection:

- https://eternalreturn.fandom.com/wiki/File:Celine.png
- https://eternalreturn.fandom.com/wiki/File:Felix.png
- https://eternalreturn.fandom.com/wiki/File:Alonso.png
- https://eternalreturn.fandom.com/wiki/File:Henry.png
